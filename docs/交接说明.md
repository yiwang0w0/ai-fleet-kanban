## 怎么验证

- Windows：`node cli/doctor.mjs`；受影响的测试直接跑 `node tests/<name>.mjs` 或 `node --test tests/<name>.test.mjs`；全量 `npm test` 交给 CI。
- 云端 Linux 容器：需要 Node 24（从 nodejs.org 下载并核对 SHASUMS256）、python3、git ≥ 2.45（容器只有 2.43 时，在 PATH 前面放一个去掉 `--no-lazy-fetch` 参数的 git 垫片）。已知在 Linux 上固定失败且与改动无关：panelauth 的 H3（磁盘观测只在 Windows 上工作）、versiontest 1 项、fleetactionstest 27 项（Windows 专属凭据文件）。
