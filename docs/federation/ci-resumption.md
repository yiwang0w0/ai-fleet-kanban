## 修复范围

- 调度拒绝启动：按 H7 检查凭据文件已删除、主体已撤销、秘密摘要清空；启动意图和外部标记仍保留，未扣额度且再次轮询不重新准备。
- 演示命令：读取本地 operator 令牌查询执行线和待审任务；以自然退出等待 Windows HTTP 句柄和自有子进程结束。面板认证规则保持。
- CLI 夹具：正确识别 `node --test` 后的全部文件；缺失第二个文件仍能检出。演示观察采用认证查询，并在启动时订阅退出，避免错过快速失败。
- 监管夹具：临时 server 副本同时识别单/双引号导入；默认锁定测试座席，只有明确验证解禁的案例可打开，防止本机环境变量污染反例。
- 桌面凭据清理：文件已删除的导出入口应报告 BAD_CREDENTIAL；内存中保留的旧令牌仍必须 UNAUTHENTICATED。撤销后禁止发布/清理历史，已有快照保持。
