# 任务版本与过期命令保护

每张本地任务新增 aggregate_version。客户端提交控制命令时，必须带它实际阅读的版本；服务端在 SQLite 写事务取得锁后比较。版本不同返回 409，不写任务和历史，不自动把旧命令改成最新版本重试。

## 版本含义

- 初始版本为 1，旧数据库迁移也从 1 起步；内容、状态、证据和裁定等字段变化会递增。
- 心跳、租约、updated_at 和 work_spans 单独变化不递增；写入相同内容不递增。
- 同一命令可包含多次有业务意义的 SQL 更新，所以版本可能跳号。它是单调比较标识，不是命令计数或时间戳。
- 版本由存储层生成，创建/编辑请求不能指定 aggregate_version。最大值为 JavaScript 安全整数上限，达到上限后拒绝继续递增，不回绕。
- 迁移与版本触发器在同一事务内安装；未来新增任务列时必须同步升级触发器覆盖范围。不要由外部脚本直接改版本。

## 接口与客户端

下面的 POST /api/tasks/:id/:action 均要求 expected_version 为正安全整数：

| action | 用途 |
|---|---|
| claim | 指定任务领取 |
| update | 编辑任务内容、线路或参数 |
| resolve | 人工或自动裁定 |
| autoreview | 保存审阅结论 |
| pin | 目标置顶 |
| release | 放行或收回 |
| reopen | 重新打开 |
| archive | 归档或恢复 |

~~~json
{"expected_version":7,"description":"基于第 7 版核对后的修改"}
~~~

缺失或格式错误返回 400；任务不存在返回 404；旧版本返回 409，并提供 expected_version 和 current_version。这个 current_version 仅帮助提示冲突，不能直接替换旧命令版本后重试。请重新阅读完整任务、核对修改意图，然后创建新的命令。

人工 CLI 先用 show 读取 aggregate_version，然后显式传 --version：

~~~text
python cli/board.py show 12
python cli/board.py edit 12 --version 7 --file payload.json
python cli/board.py take 12 --as alpha --version 8
~~~

JSON 编辑文件也可显式带 expected_version。CLI 不会自动 GET 最新版本。done/wait 仍要求原领取回执的 --run，具体见 runs.md。

面板从打开编辑窗口、移线菜单或开始填写裁定草稿时保留版本。冲突会显示错误，线路/参数/裁定不落盘；移线冲突后刷新卡片。重新打开裁定窗口不会更新旧草稿的版本，提示先保留所需文字、重新载入页面并核对任务。

审阅循环使用被审阅任务的 aggregate_version；在模型审阅期间任务若变化，迟到的通过、否决、人工确认包或失败印记均被拒绝。原 expect_updated_at 只作为附加检查保留。

## 事务与副作用

版本检查、业务修改、事件写入在同一 BEGIN IMMEDIATE 事务内完成。另一个进程不能在检查后抢先写入。失败会同时回滚版本和任务。resolve 的文件归档准备在取得锁且检查版本之后执行，因此过期裁定不会复制文件。文件系统本身不具备 SQLite 回滚语义；其他归档失败/崩溃恢复仍由原有归档校验及后续成果事务设计处理。

自动领取队列由服务端在事务内选择任务，不要求调用方预先读任务版本。已领取 worker 的心跳、重试和报告使用 run_id 隔离，允许当前执行期间追加任务说明；不会因为合法心跳造成裁定冲突。存储层的内部调用可省略 expectedVersion，由其执行实例或事务约束负责；上述外部控制入口不能省略。

## 升级与回滚

这是任务控制 HTTP/CLI 协议的有意破坏性变更。部署时停止旧服务、worker、审阅循环和其他写入者，备份数据库，然后一起升级服务端、面板、CLI 与循环。已有浏览器页面须重新载入，自动化脚本须使用原始观察版本。混合版本写入不受支持。当前开发分支尚未部署。

回滚必须停写、保留升级后数据，再恢复匹配代码和备份；不要让旧服务直接写升级后的数据库，也不要丢弃升级后新增任务或结果。

## 验收与边界

npm run test:versions 覆盖 18 项测试：八类过期控制请求、无版本/伪造版本、事务回滚、归档准备拒绝、跨进程同时编辑、CLI 正负向提交、页面草稿版本保留与可见冲突。旧行为测试的 fixtureVersion 只服务测试夹具，不能复制到产品客户端当作自动重试方案。

隔离浏览器实测：菜单打开后另一客户端更新任务，移线被拒绝且弹出错误；编辑窗口打开后任务被更新，参数修改被拒绝且提示在视口内可见。最终线路仍为 alpha、max_attempts 仍为 3。所有实测均为临时本机数据，未调用真实模型。

本批仅覆盖上述八类本地任务控制入口。目标分解、流水线等其他业务命令尚未统一接入此版本合同。尚未实现远端副本、节点凭据绑定、事件来源验证、协议协商或离线同步，不能据此宣称 T02.04 全部验收。版本号和 run_id 都不是认证凭据。
