# 全局任务视图（S08 初版）

从现有看板顶部的「全局视图」打开。每个终端单独一组，显示稳定身份、任务树、筛选结果数量和同步状态。同名终端保留不同的身份标识，改名不会改变任务所属终端。

可按终端、项目和任务标题或 UID 查找，展开任务查看说明、验收条件和执行结果。本机任务可回到本机面板定位。远端任务是已授权同步的缓存；本视图不领取、取消、裁定或改写远端任务。

## 数据与时效

- 未取得远端列表：显示「任务数量未知」，不能据此判断远端没有任务。
- 已收到空列表：显示已缓存可见 0 项；这只覆盖明确共享的数据。
- 最近同步、超过 60 秒的缓存、失败、未追平、时间异常和恢复待核对分别显示。任一项目尚未取得列表，终端不会被标为全部最近已同步。
- 同步失败保留缓存；来源恢复后缺失的任务保留「待核对」标识。
- 窗口打开时每 15 秒刷新。读取失败保留上次画面并明确提示。默认显示前 1,000 项，最多 10,000 项；超限提示筛选，不把截断数当作总数。
- 数量是当前筛选下可见任务数量，状态中的「已完成」不是项目阶段验收百分比。父任务不在筛选或分页范围内时明确提示，不制造新的父子关系。

## 接口与边界

`GET /api/fleet` 与 `GET /api/fleet/task?uid=...` 要求现有操作员 `X-Board-Token`。worker/review 令牌及外部 Origin 被拒绝。接口只返回任务展示字段，不返回验证命令、私有路径或凭据。页面复用现有面板；没有增加带令牌的新页面。

读取在一致的 SQLite 事务中完成，不自动迁移同步存储或发送网络请求。未配置同步时仍可查看本机；不兼容的同步版本提示升级。归档和撤回的远端任务不在活动视图中显示。

此版本覆盖 T08.01/T08.02 的部分本地实现。已增加可点击的跨端委派箭头和本机证据追溯，见 fleet-evidence.md。带回执的委派、取消及候选处理已接入可选操作入口，见 [fleet-actions.md](fleet-actions.md)；完整绑定/登记/验收操作界面、依赖图、历史分页、正式阶段进度和两台实体电脑验收仍未完成。列表返回有上限，但当前实现仍遍历本机和已缓存任务；大规模读取性能不是本批通过项。

## 验证

运行 `npm run test:fleet-view`。专项验证同名根、改名归属、未知与零数量、离线缓存、恢复缺失、筛选截断、敏感字段排除、读取无迁移，以及真实本机 HTTP 服务的操作员鉴权。

浏览器检查仅使用隔离模拟数据，不消耗真实模型调用额度。实际检查内容与限制见 `fleet-view-evidence.json`。
