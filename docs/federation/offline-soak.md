# 单机 30 分钟离线补验

2026-10-05，第九十三批，T05.04 的本地组成部分。产品基线 c0f7ace；脚本和实际运行模块摘要见[证据](offline-soak-evidence.json)。实体机一台、隔离节点两个，使用鉴权回环 HTTP 与真实 SQLite，不改变 Tailscale 或生产配置。

| 观察 | 实测结果 |
|---|---|
| 实际离线时间 | 1800.904 秒，以单调时钟测量 |
| 已领取任务继续执行 | 断线后 30.328 秒完成，Windows Job 清空，留在 waiting，未验收 |
| 对端离线期间 | 原副本仍为 in_progress；缓存超过新鲜度阈值显示 stale |
| 重连补齐结果 | 393.239 ms，同一任务变为 waiting |
| 重复执行与额度 | 本机始终 1 次运行、1 次合成许可；对端 0 次运行、0 个本地权威任务 |
| 所有权与停止 | 本机未重启或换实例；最后两个节点正常停止，执行器停止证据成立 |

先完成约 10.78 秒的脚本资格检查，再用同一脚本完整等待 30 分钟，没有用快进时钟替代。长实验每秒核对节点存活记录、MCP 监听状态、许可与启动次数，每分钟记录采样。对端节点关闭后，本机合成子进程继续执行；重连重启的只有对端，原执行节点保持同一实例。

## 重现

~~~powershell
npm run test:offline-soak -- .data/offline-new-report.json
~~~

需要 Windows、Node 24、Git 和 Python。必要时用 BOARD_PYTHON 指定解释器绝对路径。输出文件必须不存在；默认真实计时 1,800,000 ms，第四个参数可选择 10,000–3,600,000 ms。短时运行只适合脚本检查，不能算作 30 分钟通过。日志每分钟输出，最终 JSON 在退出收尾时写入；尚无 JSON 不代表进程已停止，不要因此另起一轮。

脚本创建临时源码和本地验收夹具，不改部署 accepted_rev。执行器是空认证目录下的合成程序，输出 Zcode 形状事件并经实际 Windows Job 监管，未调用真实 Zcode/Claude/Codex。它在约 30 秒后结束，其余时间检验离线留存与禁止重派；不声称持续运行模型 30 分钟，也不证明真实桌面会话。正常结束后关闭临时节点和数据库，清理本次临时目录。

此实验为手动按需命令，不进入每次完整 CI。T05.04 保持 in_progress，正式签收不变；实际两台 Windows 电脑、Tailscale 隧道断开/恢复、真实执行器和独立验收仍待完成。
