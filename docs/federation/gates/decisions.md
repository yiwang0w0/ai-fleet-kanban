## 权限表如何使用

[access-matrix.json](access-matrix.json) 是可审阅的权限提案，不是服务可直接加载的配置。同步阶段只有 handshake/health/pull/ack；协作阶段另列委派、取消、结果、产物与结案权限，只有访问 A 的对端另有关系登记 scopes。A 的本地登记动作走受控本机入口，不签发自身 peer 凭据。各条授权目前 enabled=false，真实 ID、epoch、endpoint 和维护者需从私有回执绑定。

逻辑角色权限与已有 astra/engine 章程分开列示，主备模型和实例没有擅自选择。对端能调用 API 不等于能启动模型，还必须通过本机 MCP 身份、运行策略及一次性许可。

## 仍需真实输入的部分

B 已提供的预检保留，不重复索要同一输出。还缺 B 看板回执及资源/工作仓信息、A/B 维护者代号、角色/集成身份绑定、连续运行预算和模型、常态保留策略及具体网络启用资料。独立审阅和必要 OP 确认未取得前，T00.03/T00.04 与 G00 均不能写成已通过；这不阻止授权范围内的本机实现和无模型验证。
