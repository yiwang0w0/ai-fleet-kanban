本项原标准为“固定 SHA、工作区、配置摘要、schema 版本”和“无其他在途改动混入”。现已备齐对应材料，状态为已实现待独立验收；这不是通过回执。

| 标准 | 实际证据 |
|---|---|
| 固定 SHA、工作区 | 从 `864feec033f4be38c929ae2d29cf683fb266516d` 导出全新隔离源码；固定 Git tree、归档和文件清单摘要。460 个文件在初始化前后摘要一致，目录中没有额外文件 |
| 固定配置 | 实际读取同目录零执行线配置；固定配置字节、空验证注册表、Node 版本及程序摘要；真实绝对路径留在本机私有目录 |
| 固定 schema | 在这个候选的新空白数据库执行列明初始化入口，记录 20 个组件版本、158 张表、449 个 schema 对象及统一摘要；SQLite 完整性检查通过 |
| 无其他在途改动混入 | 来源为固定 Git 归档，开发工作树中的未跟踪提议未进入归档；任务、运行、操作请求、对端授权、MCP 执行身份和分派记录均为零 |

完整观察值见 [candidate-baseline.json](candidate-baseline.json)，同一索引保存在 [baseline.json](baseline.json)。主要版本为 sync 5、binding/relation 4、dispatch 3、topology/workspace 2，其余已列出的组件为 1；SQLite `user_version=0` 不是全项目 schema 版本。schema 摘要算法为有序的 `[type,name,tbl_name,sql]` 行数组、UTF-8 紧凑 JSON、SHA-256，排除 `sqlite_%` 内部名称。

这是一次新基线初始化，不是全仓回归。没有创建任务、登记凭据、启动服务或调用执行器。鉴权失败统计、调度器/常驻生命周期及按需界面日志未初始化，观察文件明确列出，不能据此声称所有运行模式均已验收。
