## 批次 36：M6 失败鉴权保护

peer 网关的无效凭据才进入 10 秒失败窗口，同声明 key 5 次或全局 100 次后返回 429 / Retry-After；合法凭据先认证，不会被伪造公开 key ID 锁住。64 个标签和 overflow 限制内存，审计周期 5 秒、持久上限 512 条、24 小时查询保留；未知 schema 拒绝。正常关闭刷出，写入失败保留有界计数并对后续无效请求返回 503，成功刷出后恢复。

本机 auth-failures 命令只读已持久摘要，不新增远端查询。日志不含 token、URL、正文或转发头；声明 key 不是认证身份。Tailscale 代理后回环来源不提供远端身份，仍需实际 ACL/HTTPS 和 bearer/项目控制。保护是每进程的失败响应退避，凭据检查仍执行，不宣称流量防护、跨进程配额或无损日志。

最终去重 186 项通过、0 失败、0 跳过，新增 5 项：111 项身份/同步/恢复，74 项委派/绑定/传输，最终 peer 25 项复核只新增 1 项，其余 24 项不重复计数。首次新 HTTP 用例发现接线替换未命中，修正后旧匿名测试又检出新的 429 语义；保留路径与认证拒绝覆盖、更新精确阈值断言后全部通过。见 review-auth-evidence.json。
