# 本机多层任务树

对应 AFK-FED-001 的 MCP 拆分合同和 S06 关系基础。本批实现单个终端数据库内的父子树；跨终端委派、全局关系登记和三机验收另行实现。

## 两种持久化模式

- 新 MCP create_task 创建的根任务或目标使用 hierarchical；split_task 继承父任务模式。
- 历史任务以及未显式指定模式的原生 store.add 保持 legacy。数据库迁移只增加默认列，不改变已有 ID、父子关系、状态或事件。旧两层创建规则仍有效；旧规则需要上浮时，MCP 返回 CHAIN_LIMIT 且不创建任何子任务。
- tree_mode 在创建后不可更改。原生 store.update 拒绝传入模式字段，数据库触发器也拒绝改写。当前没有自动转换历史树的命令，跨模式重挂被拒绝。
- hierarchical 的根深度为 0，最多 32 条父子边。第 33 层创建直接拒绝，保持请求的父子语义。目标卡 kind=goal 必须是根；任意层普通任务可以再拆分。

单个终端仍可拥有多个本地根；本批尚未建立唯一的终端展示根。tree_mode 由本地存储及 MCP DTO 返回，没有加入现有严格远端投影 schema；远端投影仍使用 parent_uid 表达层级且只读。

## 结构与执行门

任务创建、重挂和领取复用有界祖先检查。不存在的父卡、父链环、混合模式、嵌套目标和超过结构上限的链不能被当作可执行根。只读查询可以查看损坏行；rootOf 返回 null。尚未迁移的新模式列缺失时，只读结构查询按 legacy 解释，不写数据库。

层级树中，已完成或归档的祖先阻止新增子任务、挂入新分支和领取后代。深层任务继续受原生放行、子任务、依赖、人工确认、锁、无进展及尝试数等门禁约束；根 WIP 上限覆盖所有深层分支。根未放行时，叶子领取失败且不产生 run 或尝试记录。

重挂在 BEGIN IMMEDIATE 内完成并校验 expectedVersion。移动分支会遍历所有后代（包括归档卡），将新父深度与分支高度相加检查上限；有正在执行的未归档后代时，重挂和脱离父卡均拒绝。结构检查最多读取 10,000 个分支节点，超出时拒绝操作；这不是整库任务数量的限制。两个独立进程并发把 A 挂到 B、把 B 挂到 A，最多一个提交成功。

没有新增父任务自动验收规则。普通叶子报告 done 仍为 waiting/review，父卡需等待子卡被授权验收后才能领取。历史显式 oneof/proves_parent 联动裁定语义仍保留，MCP 不提供这些字段；跨端证据验证及逐层独立验收合同尚未完成。

## 验证与边界

运行 npm run test:trees 和 npm run test:mcp。测试使用临时 SQLite、独立 OS 子进程和回环协议，不发起真实模型调用。覆盖 32/33 层边界、幂等拆分、历史迁移、根放行/WIP、子树整体重挂、祖先关闭、活动后代、循环/损坏、乐观版本冲突及并发防环。

全局依赖环不能靠本地父子检查证明不存在。后续需为项目建立串行关系登记与确认回执，并在登记节点离线时保留未确认关系；本批的进程竞争测试不代替多机网络分区测试。完整结果见 trees-evidence.json，完整阶段验收仍为 0/12。
