# 原生看板首批增强

本批基于远端开发版 `0afe0b9`，继续增强原 Kanban，不引入其他工作台的宿主、组件或调度。原本地 `0cf9269` 的独立第四批保留在原工作区，未混合合并。

## 使用变化

- 默认暖纸色，系统深色模式使用暖褐色；保留原首页、五栏、侧栏和原生按钮。
- 首页不再把领取直接说成开工。侧栏显示最近放行、本轮领取、启动请求及进程观察；时间使用本地日期与时刻，缺少证据写“待核实”。
- 每秒只更新侧栏状态文字；关联任务和回执变化只更新各自只读区，保留留言、焦点、选区与待第二次确认的按钮。
- 关联任务复用既有父子与前置依赖，可直接切换；完整历史仍从原追溯入口查看。列表外任务不猜测已归档或已完成。
- 智能体、推理强度及独立审阅等文案中文化；协议值、允许模型、权限、两次确认及验收门禁不变。

## 验证与边界

本地只运行受影响的首页、侧栏、执行投影、HTTP 和时间线测试；新增专项已接入现有 Windows CI，不扩大本地全量回归。

实测：首页 18 项（含中文强度与暖色对比度）、侧栏 5 项、执行投影 9 项、隔离 HTTP 1 项、时间线 23 项均通过。这里分别保留各套件口径，不把重复运行累计为新覆盖。

隔离浏览器使用合成任务，验证桌面与 390px 窄屏、暖浅/深色、父任务跳转、前置依赖可见、刷新保留选中任务及留言。所有执行器保持停止，不连接现有试用数据，不调用真实模型。

CLI 旧路径没有持久可信的模型开工回执，仍明确显示“待核实”；Broker 的最终进程观察只表示已观测事实，不冒充实时采集或供应商调用证明。本批不宣称全站中文化完成，不接入直接 API，也不替换现有运行服务。
