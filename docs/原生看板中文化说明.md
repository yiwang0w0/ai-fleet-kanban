# 原生看板中文化补齐

本批接续原生首批 `ef2ad8f`，只补全自有界面的中文展示，不引入其他工作台的组件、布局或国际化框架。暖纸／暖褐色变量与 CSS 保持不变。

## 本批范围

- 裁定弹窗及卡片摘要：最终裁定、推荐方案、成本与风险、附件用途、交接目录、证据／原因与回执说明。
- 设置与辅助信息：智能体、执行器、命令行程序、推理强度、运行时长、用量单位，以及表单、时间轴与滑块的中文无障碍名称。
- 全局视图和技术信息：各语义域分别转换状态；未知值显示待核实，不把接收等同验收、领取等同开工、请求启动等同已启动。
- 配对、请求和错误提示：明确浏览器异常给中文下一步，中文业务消息保留，未知错误附原始信息。有限独立审阅发现的 `timeout` 子串误匹配已收窄，文件或业务名中出现该词不会再冒充网络超时。

品牌与模型名、CLI 命令、路径、机器字段和值、用户／模型原文、第三方日志保留原样。旧记录和自定义名称不批量改写；本批不新增权限、任务流程、直接 API 通道或自动重试。

## 验证

本地按改动运行：首页 18 项、裁定附件 25 项、配对客户端 9 项通过；文案测试 8 组分组定向通过，覆盖语义域隔离、原文保留、错误负例、中文计数、无障碍和暖色变量。新套件已接入 `npm test`、`test:home` 及既有 Windows CI 步骤，不重复跑首批执行投影和全仓测试。

临时真实看板验证了无效 JSON 的中文提示及原 HTTP 合同、配对连接失败中文、设置滑块中文与原枚举提交、裁定与附件提示、用户英文原文保留，以及 1440px／390px 和暖深色显示。设置和裁定均无横向溢出，改动页面无脚本错误。临时夹具最初的错误码假设、人工闸识别及裁定数据准备已修正；这些不是产品失败，也不累计为新增测试覆盖。

所有执行器保持停止，未调用真实模型。临时服务已关闭，合成任务和临时令牌已清理；现有运行服务、任务及数据未改。全量回归留给 CI，本批不自动推送或部署。
